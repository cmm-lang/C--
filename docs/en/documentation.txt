13. Runtime Error
================================================================================
Format:
line: string, symbol: symbol RUNTIME FAULT Signal n (SIGxxx):
line
^ ^ ^ pointer to a string
REASON: the reason

Runtime Fault — critical error system in C-- (analogous to Segment Fault in C). They are calculated in runtime.

Signal 1 (SIGDIV) - Division by zero
Signal 2 (SIGTYPE) - invalid types for example: const c: char = "wrong"
Signal 3 (SIGSTACK) - Stack Overflow

Example of Signal 1 occurrence:
const temp = 10 / 0
Error:
line: 1, symbol: 12 RUNTIME FAULT Signal 1 (SIGDIV):
let temp = 10 / 0
            ^^^
REASON: Division by zero

Example of Signal 3 occurrence:
const arr[1000000] = [1, 2, 3]  // too big for stack
line: 1, symbol: 8 RUNTIME FAULT Signal 3 (SIGSTACK):
const arr[1000000] = [1, 2, 3] // too
        ^^^
REASON: too big for stack
